STEAM CUSTOM ACHIEVEMENTS v0.28.0 - MULTI-GAME

Adds the Xbox 360 achievement list to the Steam Library page of games whose
Steam version has no achievements. Each supported game gets the same ACHIEVEMENTS
sidebar card, header stat and "View My Achievements" popup that AC2 had.

GAMES IN THIS BUILD

  Assassin's Creed                  15100       44             44 (game's own record + save)
  Assassin's Creed II               33230       50             41 (autosave parser + game's checklists)
  Assassin's Creed Brotherhood      48190       60             50 (game's own record + save)
  Call of Duty 4: Modern Warfare    7940        37             24 (profile config.cfg)
  Call of Duty: World at War        10090       66             22 (profile config.cfg)
  Fable III                         105400      60             60 (game's own record via XLiveEmu)
  Mass Effect                       17460       49             45 (game's own achievement profile)
  Mass Effect 2                     24980       62             61 (game's own achievement profile)
  Thrillville: Off the Rails        6080        50             18 (park save: missions, owner level)

Automatic entries unlock by themselves a few seconds after the game writes its
progress. Everything else has a "Mark as unlocked" button in the popup.

NEW IN v0.4.1
- Record mode can narrow down over several recordings, like a RetroAchievements
  memory search. After a recording, record the same achievement again with
  "Keep narrowing" ticked (it is ticked for you):
    * Done: progress happened (e.g. you smashed one more gnome). Only values
      that changed again, in the same direction, are kept.
    * Done, no progress: you played without making progress. Everything that
      changed anyway (play time, gold...) is ruled out.
  After two or three recordings, usually one value is left: the counter for that
  achievement. Narrowing lasts until Steam restarts or you start a fresh search.

NEW IN v0.4.0
- Record mode (View My Achievements > Settings > Record an achievement). It works
  like a RetroAchievements memory search, but on save files:
    1. pick the achievement you are about to earn and press Start (for games
       without automatic tracking, paste the game's save folder first),
    2. earn it in game and let the game save,
    3. press Done.
  Every value that changed is listed. Values that now equal a number from the
  achievement (e.g. 50 in "Destroy all 50 gnomes") are marked "matches" and
  listed first. For games with automatic tracking it also says whether the
  plugin's own rule unlocked it. Text files (CoD config.cfg) are compared line
  by line, Fable III hero saves as named statistics, other files as changed
  bytes and the small numbers around them. Compressed saves show raw byte
  changes only; the saved copies are what lets them be mapped.
  Copies of the changed files (before and after) and a report are written to
  the plugin's recordings folder (or your temp folder if that is not writable).
  Zip one recording's files and send them to turn that achievement automatic.
- Real Xbox pictures: in Chrome or Edge, open the game's achievement list
  (TrueAchievements, Exophase...), scroll until every picture has loaded, press
  Ctrl+S and save as "Webpage, Single File" (.mhtml). Then use Settings >
  Achievement pictures > Load from saved page. Each achievement name on the page
  is paired with its picture; badges used many times on the page are ignored.
  Send the .mhtml files to have the pictures built into the plugin like AC2's.

- Fixed: the installer only copied some backend files, so INSTALL_OR_REPAIR.cmd
  could leave out collectible_rules.lua and tracker_rules.lua. It now copies
  and verifies every file.

INSTALL / UPDATE
1. Exit Steam completely using Steam > Exit.
2. Extract All from the ZIP. It contains one steam-custom-achievements folder.
3. Replace the existing steam-custom-achievements folder in Millennium's plugins
   directory with this entire folder (include backend and .millennium), or run
   INSTALL_OR_REPAIR.cmd from the extracted folder.
4. Start Steam and confirm Steam Custom Achievements (Local) is enabled.
5. Open any supported game's Library page. The ACHIEVEMENTS section appears
   below Friends Who Play. View My Achievements opens the full list.

WHERE SAVES ARE FOUND
- AC2: Ubisoft savegames folders and <game>\savegames (unchanged).
- CoD 4 / World at War: <Steam library>\steamapps\common\<game>\players\profiles,
  the Windows VirtualStore copy of that folder, and
  %LOCALAPPDATA%\Activision\CoD4 (or CoDWaW)\players\profiles. The newest
  profile with campaign progress is used.
- Fable III: %USERPROFILE%\Saved Games\Lionhead Studios\Fable 3\<profile>.
  The newest hero*_herosave.bin is used (fail-quest copies are ignored).
If nothing is found, open View My Achievements > Settings and paste the path of
the save file or folder (for CoD, config.cfg or the profile folder; for Fable III, a
*_herosave.bin or its profile folder).

FILES / PRIVACY
The backend opens game saves and configs read-only. It writes only this
plugin's configuration and, when you press Done in record mode, the copies and
report in the recordings folder, and with capture on, copies of changed saves
in recordings\<game>. No game file changes, injected DLLs, Steamworks
unlock calls, credentials, telemetry or network requests. These are custom
local achievements, not official Steam profile achievements. Reinstalling with
INSTALL_OR_REPAIR.cmd moves the old plugin folder, recordings included, to
custom-achievement-backups.

IF SOMETHING IS MISSING
Plugin absent from Millennium: run INSTALL_OR_REPAIR.cmd and send INSTALL_REPORT.txt.
Card absent: open the game's Library page, wait a few seconds, then send a
screenshot plus the output of this in SharedJSContext's Console
(Win+R: steam://millennium/settings/devtools/open):

JSON.stringify(window.PLUGIN_LIST?.["steam-custom-achievements"]?.diagnostics?.() ?? {error:"Frontend not loaded"}, null, 2)
