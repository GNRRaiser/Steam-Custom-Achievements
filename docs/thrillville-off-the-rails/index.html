Thrillville: Off the Rails Steam achievements

Thrillville: Off the Rails has no achievements on Steam, but the Xbox 360 version has 50. Steam Custom Achievements is a free plugin that adds all 50 of them to Thrillville: Off the Rails in your Steam Library (Steam app 6080). 18 unlock automatically and 32 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Thrillville: Off the Rails achievements unlock

The plugin reads your newest park save (AppData\Local\LucasArts\Thrillville 07\Save). The five story missions (Critics, Sabotage, Hypnosis, Robots, Traitor) unlock by themselves when the game saves after you finish them, and each park achievement (Explorer, Giant, Holiday, Otherworlds) once a save from that park has an open mission. Propaganda, The Rainbow and Disc Jockey unlock when you finish Propaganda Hunt!, Spray Away and Disc Collection (each is "collect all 6"); Coaster Boaster when you finish Whoa Designer or Whoa, Nelly! (build a brand new coaster); Putt putt power with Duffer's Paradise (build a mini golf course from pieces); Whoa with Whoa, Nelly! or Burning Circuits (a whoa coaster). Thrillville Talent, Sensation and Phenomenon unlock at park owner level 2, 5 and 10, read from the save's statistics. The mission names come from the game's own park files. The rest are marked by hand for now; Capture while I play still logs each mission that changes.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
