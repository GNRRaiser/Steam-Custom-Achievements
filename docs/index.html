Steam achievements for games that only had them on Xbox 360 and PS3

Steam Custom Achievements is a free Millennium plugin that adds the Xbox 360 achievement list, plus the PS3 platinum, to 11 PC games that have no achievements on Steam. Each game gets an Achievements card on its Steam Library page, unlock popups, and a full achievement list, in desktop Steam and Big Picture mode.

How it works

The plugin reads each game's save files or profile (read only) and unlocks an achievement a few seconds after the game records your progress, with a Steam style popup and sound. Achievements you earned before installing unlock the first time it reads your saves. Anything the save does not record has a "Mark as unlocked" button. Your unlocks are kept when you update.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements (Local) is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.

Questions

Why do these games have no achievements on Steam?

Many PC ports from the Xbox 360 era used Games for Windows Live or had no PC achievements at all, so their Steam pages never got any. The Xbox 360 and PS3 versions did have them. This plugin brings those lists to Steam.

Do the achievements show on my Steam profile?

No. They show in your own Steam client only: on the game's Library page, the achievement list, popups when you unlock one, and Big Picture mode. Steam does not let anyone add real achievements to a game they did not publish.

Do I have to unlock them again by hand?

Mostly not. The plugin reads your game saves (read only, it never changes them) and unlocks an achievement a few seconds after the game records it, including ones you earned before installing. The few it cannot detect have a "Mark as unlocked" button.

Is it safe?

The plugin makes no network connections, never changes your saves, and only writes to its own folder. The source code is on GitHub. Only download it from the GitHub Releases page or the Steam guide.

Does it work in Big Picture mode and with a controller?

Yes. Big Picture shows an Achievements section on the game page and a full list you can browse with a controller.

Can you add another game?

Yes, games are added one folder at a time. Open an issue on GitHub with the game's name, or follow ADDING_A_GAME.md to add it yourself.
