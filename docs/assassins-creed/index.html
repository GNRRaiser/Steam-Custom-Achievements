Assassin's Creed Steam achievements

Assassin's Creed has no achievements on Steam, but the Xbox 360 version has 44. Steam Custom Achievements is a free plugin that adds all 44 of them to Assassin's Creed in your Steam Library (Steam app 15100). All 44 unlock automatically.

Download from GitHubSteam install guide

How Assassin's Creed achievements unlock

Assassin's Creed keeps its own record of every achievement in its save (%APPDATA%\Ubisoft\Assassin's Creed\Saved Games). The plugin reads it, so all 44 unlock by themselves a few seconds after the game saves following the moment the game awards them. The story objectives and the save's own lists back it up: Welcome to the Animus, Hero of Masyaf, The Punishment for Treason, all nine Blood achievements, Personal Vendetta (60 Templars), every flag Keeper and Fearless (91 viewpoints) also unlock from them, each shown as progress, and Eagle's Prey, Swiftness, Talon, Dance and March of the Pious show the game's running counts. Record an achievement and Capture while I play still watch the same folder.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements (Local) is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
