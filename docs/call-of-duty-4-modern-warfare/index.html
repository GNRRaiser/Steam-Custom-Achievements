Call of Duty 4: Modern Warfare Steam achievements

Call of Duty 4: Modern Warfare has no achievements on Steam, but the Xbox 360 version has 37. Steam Custom Achievements is a free plugin that adds all 37 of them to Call of Duty 4: Modern Warfare in your Steam Library (Steam app 7940). 24 unlock automatically and 13 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Call of Duty 4: Modern Warfare achievements unlock

Mission, Veteran and intel achievements unlock a few seconds after the game records campaign progress in your profile's config.cfg (when a mission ends). Feats inside missions are marked by hand.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
