Mass Effect Steam achievements

Mass Effect has no achievements on Steam, but the Xbox 360 version has 49, plus a PS3 platinum trophy. Steam Custom Achievements is a free plugin that adds all 50 of them to Mass Effect in your Steam Library (Steam app 17460). 45 unlock automatically and 5 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Mass Effect achievements unlock

Mass Effect on PC keeps the Xbox 360 achievements in its own profile (Documents\BioWare\Mass Effect\Save\Profile.MassEffectProfile, shared by all characters). The plugin reads that file, so 45 achievements unlock by themselves a few seconds after the game records them. Scholar, Completionist, Tactician and Medal of Exploration are marked by hand until their profile slots are confirmed.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
