Assassin's Creed Brotherhood Steam achievements

Assassin's Creed Brotherhood has no achievements on Steam, but the Xbox 360 version has 60, plus a PS3 platinum trophy. Steam Custom Achievements is a free plugin that adds all 61 of them to Assassin's Creed Brotherhood in your Steam Library (Steam app 48190). 50 unlock automatically and 11 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Assassin's Creed Brotherhood achievements unlock

Brotherhood records its own achievements (Settings > Stats > Achievements) in the OPTIONS file next to your save in Saved Games\Assassin's Creed Brotherhood\SAVES. The plugin reads that record and the newest save, so the 50 single-player and Da Vinci Disappearance achievements unlock a few seconds after the game unlocks them. The 10 multiplayer ones are marked by hand, since the servers are shut down.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
