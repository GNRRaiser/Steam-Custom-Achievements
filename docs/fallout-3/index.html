Fallout 3 - Game of the Year Edition Steam achievements

Fallout 3 - Game of the Year Edition has no achievements on Steam, but the Xbox 360 version has 72. Steam Custom Achievements is a free plugin that adds all 72 of them to Fallout 3 - Game of the Year Edition in your Steam Library (Steam app 22370). All 72 unlock automatically.

Download from GitHubSteam install guide

How Fallout 3 - Game of the Year Edition achievements unlock

Fallout 3 lost its Games for Windows Live achievements in the 2021 Steam update and never got Steam ones, so these are the Xbox 360 list (base game and the five DLCs). The plugin reads your newest save in Documents\My Games\Fallout3\Saves: finished quests, the Pip-Boy statistics (people and creatures killed, locks, terminals, speech, locations, bobbleheads) and your level and karma. A save only holds your karma now, so a level achievement unlocks for the karma you have when the save is read. Weaponsmith, The Bigger They Are..., Mill Worker, Alien Archivist and Bog Walker come from the counters the game's own achievement scripts keep in the save.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements (Local) is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
