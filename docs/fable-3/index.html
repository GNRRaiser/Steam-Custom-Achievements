Fable III Steam achievements

Fable III has no achievements on Steam, but the Xbox 360 version has 60. Steam Custom Achievements is a free plugin that adds all 60 of them to Fable III in your Steam Library (Steam app 105400). All 60 unlock automatically.

Download from GitHubSteam install guide

How Fable III achievements unlock

Fable III keeps its own record of the achievements you have earned when it runs through XLiveEmu (Fable 3\XLiveEmu\Player1\Achievements\Achievements.txt in the game folder). The plugin reads that record, and your hero's statistics (Saved Games\Lionhead Studios\Fable 3), so all 60 achievements, Traitor's Keep included, unlock a few seconds after the game awards them.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements (Local) is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
