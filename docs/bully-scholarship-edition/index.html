Bully: Scholarship Edition Steam achievements

Bully: Scholarship Edition has no achievements on Steam, but the Xbox 360 version has 43, plus a PS3 platinum trophy. Steam Custom Achievements is a free plugin that adds all 44 of them to Bully: Scholarship Edition in your Steam Library (Steam app 12200). 34 unlock automatically and 10 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Bully: Scholarship Edition achievements unlock

The plugin reads your newest save in Documents\Bully Scholarship Edition (BullyFile1-6) when the game saves. The five chapter achievements unlock from the save's chapter, Perfectionist at 100% on the load screen, Mission Accomplished when the game marks every mission passed, the class achievements from how many classes you have finished all five levels of, The Champion from the 14 bike races, and the counter achievements (distances, go-kart wins, time out after curfew, kisses, flowers, clothes, trouble points, eggs, wedgies, taunts, knockouts, sodas, bottles, room trophies, bikes jacked and more) from the game's own Stats screen numbers, which show here as n / total. Errands, jobs, the paper route, money, respect and the carnival and arcade games are marked by hand for now.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
