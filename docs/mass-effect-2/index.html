Mass Effect 2 Steam achievements

Mass Effect 2 has no achievements on Steam, but the Xbox 360 version has 62, plus a PS3 platinum trophy. Steam Custom Achievements is a free plugin that adds all 63 of them to Mass Effect 2 in your Steam Library (Steam app 24980). 61 unlock automatically and 2 have a "Mark as unlocked" button.

Download from GitHubSteam install guide

How Mass Effect 2 achievements unlock

Mass Effect 2 on PC records its achievements in its own profile (Documents\BioWare\Mass Effect 2\BIOGame\Profile\Player1.prf, shared by all characters), the same list it shows under Extras. The plugin reads that file, so 61 achievements, DLC included, unlock by themselves a few seconds after the game records them. Highly Trained is an Xbox 360 achievement the PC game doesn't have, so it is marked by hand.

Install

  1. Install Millennium 3.x for Steam on Windows.
  2. Download the latest steam-custom-achievements-vX.Y.Z-share.zip from GitHub Releases.
  3. Exit Steam completely (Steam > Exit), extract the ZIP and run INSTALL_OR_REPAIR.cmd.
  4. Start Steam, check that Steam Custom Achievements (Local) is on in Millennium > Plugins, and open a supported game in your Library.

The step by step Steam guide has pictures and fixes for common problems.
