Record mode saves its files here (View My Achievements > Settings > Record an achievement).

Each recording writes:
  <game> <date time> <achievement> report.txt    what changed, matches marked with <==
  <game> <date time> <achievement> report.json   the same, for tools
  <game> <date time> <achievement> before <file> copy of each changed save file before
  <game> <date time> <achievement> after <file>  and after you earned the achievement

Zip the files of one recording and send them to add that achievement to automatic
tracking. Deleting them is safe; the plugin never reads this folder.
