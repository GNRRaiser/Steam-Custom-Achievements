# FAQ

**Do the achievements show on my Steam profile?**
No. They show only in your own Steam client. Steam doesn't let anyone add achievements to a game on your profile except the game's developer.

**Do they count toward my Steam level, badges or perfect games?**
No, for the same reason.

**Can I get banned for this?**
The plugin doesn't touch the games at all. It only reads save files and draws extra things in Steam's own window. It's an unofficial plugin, so it isn't supported by Valve or the games' publishers.

**Does it change my saves?**
No. It opens saves read-only and never writes to them. It only writes to its own plugin folder and Millennium's settings.

**Does it connect to the internet?**
No. The plugin makes no network connections. Unlock rates and pictures are built in.

**Where do the achievements come from?**
Each game's Xbox 360 list, plus the PS3 platinum where the game has one. Unlock rates are the share of tracked Xbox 360 players on TrueAchievements who earned each one.

**Why are some achievements manual?**
The plugin can only unlock what the game writes down. Some achievements are one-off moments (a kill streak inside a mission, a multiplayer match) that no file records. The game's page on this wiki lists which ones.

**I earned achievements before installing. Do I have to replay?**
No. The plugin reads your existing saves and unlocks what you've already done the first time it reads them.

**Is my progress tied to my Steam account?**
No. It's stored on your PC, per game. Use **Backup** in Settings to move it to another PC.

**Does it work in Big Picture mode / on Steam Deck?**
Big Picture mode, yes: see [Big Picture mode](Big-Picture-Mode). It's built and tested on Windows; Linux and Steam Deck haven't been tested.

**Can you add my game?**
Maybe! Open an issue with the game's name. Games whose Steam version has no achievements but which had them on Xbox 360, PS3 or Games for Windows Live are the best fit. See the [Roadmap](Roadmap) for how adding games might get easier, and [Adding a game](Adding-a-Game) if you want to help.

**Can I share the plugin?**
Yes, it's [MIT licensed](https://github.com/GNRRaiser/Steam-Custom-Achievements/blob/main/LICENSE). Please share the release ZIP or a link to [Releases](https://github.com/GNRRaiser/Steam-Custom-Achievements/releases), not a zip of your installed plugin folder.
