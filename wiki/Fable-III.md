# Fable III

| Steam app ID | Achievements | Unlock automatically |
| --- | --- | --- |
| 105400 | 60 | 60 |

Full list with pictures: [Fable III on the website](https://gnrraiser.github.io/Steam-Custom-Achievements/fable-3/)

## What the plugin reads

The XLiveEmu record in the game folder (`Fable 3\XLiveEmu\Player1\Achievements\Achievements.txt`) and your hero save in `%USERPROFILE%\Saved Games\Lionhead Studios\Fable 3`

## What unlocks by itself

When Fable III runs through XLiveEmu (a common way to play it now that Games for Windows Live is gone), the emulator keeps the game's own record of earned achievements. The plugin reads it, so all 60, Traitor's Keep included, unlock a few seconds after the game awards them. The statistic achievements (gnomes and so on) also count from your hero save and show progress.

## Marked by hand

None, as long as you play through XLiveEmu. Without it, only the statistic achievements can be read from the hero save.

If nothing unlocks, see [Troubleshooting](Troubleshooting).
