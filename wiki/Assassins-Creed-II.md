## What the plugin reads

Ubisoft Connect's save folder, usually `C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\savegames\<long number>\<number>`

## What unlocks by itself

The plugin reads AC2's autosaves. Story sequences, tombs, assassination contracts, races, collectibles (feathers, statuettes, glyphs, viewpoints), the villa and the game's own checklists (Art Connoisseur, Perfect Harmony, Show Your Colors) all unlock a few seconds after the game autosaves. Each "Complete DNA Sequence" achievement waits for the sequence's real last memory.

[AUTO_TRACKING.md](https://github.com/GNRRaiser/Steam-Custom-Achievements/blob/main/AUTO_TRACKING.md) lists exactly what each achievement reads.

## Marked by hand

Street Cleaner, Fly Swatter, Messer Sandman, Doctor, No-hitter, Lightning Strike, Sweeper, High Dive and Mailman. These are one-off moments the game never writes down anywhere, so there is nothing to read.

## Tips

If AC2 isn't found automatically, use **Settings > Auto-detect save**, or paste the save folder above.

If nothing unlocks, see [Troubleshooting](Troubleshooting).
